## 安装方法

1. 下载 `2FA-1.1-debug.apk` 到手机
2. 点击安装，若提示"未知来源"，在系统设置里允许该来源安装
3. 因为是 debug 签名，部分系统会提示风险，属正常现象，继续安装即可

> 卸载旧版再安装新版本，或直接覆盖安装均可。

## 功能

- TOTP 双因素验证码生成
- 支持 SHA1 / SHA256 / SHA512 三种算法
- 支持 6 位 / 8 位验证码
- 支持自定义周期（5～300 秒）
- 支持 `otpauth://` 链接导入（扫描/粘贴）
- 支持剪贴板导入、文件导入、文件导出
- 账户搜索、置顶、重命名、复制密钥
- 验证码到期颜色提示

## 关于权限

本应用**不申请任何 Android 权限**。导入导出使用系统的文件选择器（SAF），
因此也不需要存储权限。账户数据仅保存在本机应用私有目录。

## 自己编译

仓库根目录提供了两个脚本：

- Linux / macOS / WSL：`bash build-apk-linux.sh --setup`
- Windows PowerShell：`powershell -ExecutionPolicy Bypass -File build-apk.ps1`

产物路径：`app/build/outputs/apk/debug/app-debug.apk`

也可以直接用 Android Studio 打开本仓库，选择 **Build → Build APK(s)**。
