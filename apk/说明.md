## 1.5 改动

这一版专门解决「为什么说它不合法」这件事。之前确实有拦截，现在全部拆掉了。

### 一、密钥不再有任何合法性校验

旧代码在添加账户时有三道拦截：

| 拦截点 | 旧行为 | 现行为 |
|---|---|---|
| 长度 | Base32 解码后不足 10 字节 → 报「密钥无效」 | **取消** |
| 字符集 | 含非 A-Z2-7 字符 → 报「密钥无效」 | **取消** |
| 重复 | 同一密钥已存在 → 报「该密钥已存在」 | **取消** |

现在只要输入框里**有内容**，就一定能加进来。

拿「几个字母」举例：输入 `e`、`abc`、`hello`、甚至 `hello world`，
以前会被 Base32 校验挡回去，现在都能添加，并且能算出验证码。

### 二、密钥取值改为「永不失败」的双路径

放开校验只是第一步——如果密钥算不出结果，加了也没用。所以密钥派生逻辑改成两级兜底：

```
deriveKey(输入)
  ├─ 1. 先按标准 Base32 解码  → 得到字节就用它
  └─ 2. 解不出（含非法字符/太短）→ 退回 UTF-8 原始字节
```

两条路径都能产出非空字节参与 HMAC 运算，所以**任何非空输入都必然有验证码**。

标准密钥（如 `JBSWY3DPEHPK3PXP`）仍然走第一条路径，
RFC 6238 官方向量结果完全没变——放开限制没有破坏正确性。

### 三、其他限制一并收敛

- 位数：以前超出 1～18 会弹错误拦下来，现在自动收敛到安全区间，不拦截
- 周期：同上，超出 5～300 秒自动收敛
- 导入：以前要求每行都是合法 Base32 且 ≥16 字符，现在非空行一律收下

### 四、底部快速验证区重做

按你的要求改成「贴密钥 → 立即出码 → 点击复制」：

- **密钥输入框**：粘贴或手输任意密钥，输入内容一变就重算，不做任何校验
- **验证码**：大号等宽字体实时显示，6 位切 3+3、8 位切 4+4
- **复制按钮**：点一下就把当前验证码复制到剪贴板
- **参数说明**：右侧显示当前使用的 `算法 · 位数 · 周期`
- **进度条**：显示本轮剩余时间，最后 5 秒转橙色

另外，**点击上方账户卡片**时，该账户的密钥与参数会自动填进快速区，
便于直接复制验证码。

### 五、图标重做

按你给的参照图重做：**纯黑底 + 红色线条，线条全部是 45 度斜线，交叉成 X 形**。

- 线条端点做垂直于线身的斜切收口，不是圆头
- 8 倍超采样绘制，斜线边缘平滑无锯齿
- 5 种密度 PNG 全覆盖：mdpi 48 / hdpi 72 / xhdpi 96 / xxhdpi 144 / xxxhdpi 192
- 方形（圆角矩形底）与圆形两套
- 自适应图标前景层为红色斜线、背景层为纯黑，圆形图标时线条自动裁进圆内

## 1.4 修复内容（启动闪退的真正根因）

### 启动闪退

`activity_main.xml` 里的搜索框 `TextInputLayout` 通过 `boxStrokeColor`
引用了 `@color/field_stroke`。这个选择器当时只有带状态的两项：

```xml
<selector xmlns:android="http://schemas.android.com/apk/res/android">
    <item android:color="@color/app_primary" android:state_focused="true" />
    <item android:color="@color/app_line"    android:state_focused="false" />
</selector>
```

**缺少不带任何状态的默认项。** 控件在既不聚焦、又不处于「明确失焦」的中间状态时
取不到颜色，系统抛：

```
android.content.res.Resources$NotFoundException:
    Can't find ColorStateList from drawable resource ID #0x7f05006c
```

这个异常发生在 `setContentView` 的 inflate 阶段，**Activity 还没创建完就抛了**，
进程被系统直接杀掉 —— 表现为「点进去直接闪退」，连报错都看不到。

修复：补上无状态默认项；并新增回归测试，强制要求所有 `res/color/` 选择器都带默认项。

### 定时刷新空指针

`refreshCodes()` 由每秒定时器调用，但直接用了 `adapter.notifyDataSetChanged()` 没判空。
视图绑定失败时 `adapter` 永为 null，定时器每秒崩一次。已加判空与 `ready` 标志。

## 界面结构

界面分上下两块，比例约 **3 : 1**。

**上部（约 3/4）· 账户管理**

- 顶部标题栏：应用名 + 全局倒计时 + 「添加」按钮
- 搜索框：按名称、发行方或密钥过滤
- 工具条：导入 / 导出 / 排序
- 账户卡片列表：每张卡片显示名称、算法参数、大号验证码、剩余时间进度条、复制按钮
- 卡片右上角「⋮」可编辑、置顶、复制密钥、删除
- 点击卡片把该账户的密钥与参数带入下方快速区

**下部（约 1/4）· 快速验证**

- 密钥输入框：粘贴或输入任意密钥，立即出码
- 一键复制按钮
- 大号验证码 + 参数说明（算法 · 位数 · 周期）
- 剩余时间进度条，剩余 5 秒内转为橙色

## 功能

- TOTP 双因素验证码生成
- **位数不受限制**：1～18 位均可，7 位、9 位这类非标准位数同样正确输出
- **密钥不受限制**：任意文本都可以作为密钥，标准 Base32 与普通文本都能算出结果
- 支持 SHA1 / SHA256 / SHA512 三种算法
- 支持自定义周期（5～300 秒）
- 支持 `otpauth://` 链接导入，自动识别算法、位数、周期
- 新增账户名称留空时，自动命名为「验证器一」「验证器二」……
- 支持剪贴板导入、文件导入、文件导出
- 账户搜索、置顶、重命名、编辑、复制密钥
- 快速验证区：贴密钥即时出码，一键复制

## 关于「不设限制」的两个说明

**1. 位数为什么是 1～18**

位数本身任意，但计算时要用 `10^digits` 取模。`long` 类型能安全表示到 `10^18`，
所以上限取 18。超过会自动收敛，不会报错拦你。

**2. 非标准密钥怎么算**

标准 TOTP 要求密钥是 Base32。遇到不是 Base32 的输入（比如几个字母、带符号的串），
程序会把这段文本按 UTF-8 直接当作字节密钥参与 HMAC 运算。

所以「几个字母也能出码」是有确定算法支撑的，不是随便编一个数给你 ——
同样的输入每次结果都一样，不同输入结果不同。

## 关于权限

本应用**不申请任何 Android 权限**。导入导出使用系统文件选择器（SAF），
因此不需要存储权限。账户数据仅保存在本机应用私有目录。

## 测试

测试分两层。

### 第一层：算法与静态审计（只依赖 JDK）

```bash
bash tools/algorithm-tests/run.sh
```

共 135 项 + 1 套启动路径审计：

- `TotpTest`：RFC 6238 官方向量、多算法、多位数
- `UriTest`：otpauth 解析、中文编码、往返一致性
- `ImportTest`：混合格式导入、去重、边界情况
- `AnyDigitTest`：1～18 位任意位数的正确性验证
- `StartupAudit`：解析 APK 资源表，核对所有 id / 颜色 / 图形 / 样式 / 文案引用

### 第二层：Android 运行时测试（Robolectric，需要 Android SDK）

```bash
bash tools/setup-robolectric.sh          # 首次运行，拉取依赖
bash tools/algorithm-tests/run.sh --android
```

共 50 项，会把 Activity 真的创建出来跑一遍：

- `NoBarrierTest`：验证所有拦截点已放开（16 项）
  - 几个字母 / 短密钥 / 非标准字符 / 重复密钥都能添加
  - 任意输入都能算出验证码，且结果稳定可重复
  - 快速区输入即出码、清空回占位符、参数跟随账户
  - 标准 RFC 向量结果未变（确认放开限制没破坏正确性）
- `LaunchTest`：Activity 创建、完整生命周期、配置重建、关键控件绑定、图标质量
- `LayoutInflateTest`：三个布局全部真实 inflate，校验主题、颜色选择器、图形、样式
- `ColorSelectorRegressionTest`：颜色选择器必须有默认项（1.4 闪退的回归防护）
- `TotpRuntimeTest`：在真实 Android 运行时里验证 TOTP 与分组显示
- `DiagnoseTest`：初始化异常诊断，会把 `showFatal()` 捕获到的堆栈打印出来

> 注：Robolectric 需要约 150MB 的 `android-all` jar。国内直连
> `repo1.maven.org` 经常失败，`tools/setup-robolectric.sh` 会自动改用阿里云镜像
> 下载并配好离线仓库。
