## 安装方法

1. 下载 `2FA-1.2-debug.apk` 到手机
2. 点击安装，若提示「未知来源」，在系统设置里允许该来源安装
3. 因为是 debug 签名，部分系统会提示风险，属正常现象，继续安装即可

> 从 1.0 / 1.1 覆盖安装即可，账户数据会保留；也可先卸载旧版再装。

## 界面结构

界面分上下两块，比例约 **3 : 1**：

**上部（约 3/4）· 账户管理**

- 顶部标题栏：应用名 + 全局倒计时 + 「添加」按钮
- 搜索框：按名称、发行方或密钥过滤
- 工具条：导入 / 导出 / 排序
- 账户卡片列表：每张卡片显示名称、算法参数、大号验证码、剩余时间进度条、复制按钮
- 卡片右上角「⋮」可编辑、置顶、复制密钥、删除
- 点击卡片即切换为「当前账户」，同时同步到下方快速区

**下部（约 1/4）· 快速验证码**

- 显示当前选中账户的名称与大号验证码
- 一键复制按钮
- 剩余时间进度条，剩余 5 秒内转为橙色提示

## 功能

- TOTP 双因素验证码生成
- **位数不受限制**：1～18 位均可，7 位、9 位这类非标准位数同样正确输出
- 支持 SHA1 / SHA256 / SHA512 三种算法
- 支持自定义周期（5～300 秒）
- 支持 `otpauth://` 链接导入，自动识别算法、位数、周期
- 新增账户名称留空时，自动命名为「验证器一」「验证器二」……
- 支持剪贴板导入、文件导入、文件导出
- 账户搜索、置顶、重命名、编辑、复制密钥
- 验证码到期颜色提示（剩余 5 秒内转橙）

## 关于位数

这是本版重点修正的地方。旧版把位数写死成「6 位或 8 位」两种模式，
传入 7 位会按 6 位计算，属于错误行为。

新版改为通用公式 `10^digits`，1～18 位任意长度都按输入值真实计算。
边界说明：18 位是 `long` 类型能安全表示的 `10^n` 上限，因此上限取 18。

已通过 61 项专项测试覆盖这一点，包括：

- 1～18 位逐位验证输出长度与全数字格式
- 1～18 位均满足「等于基准值后 N 位」的数学关系
- 6 位与 7 位结果必须不同（防止写死逻辑回归）
- 3 种算法 × 18 种位数 = 54 组合全部正常

## 关于权限

本应用**不申请任何 Android 权限**。导入导出使用系统文件选择器（SAF），
因此不需要存储权限。账户数据仅保存在本机应用私有目录。

## 自己编译

仓库根目录提供了两个脚本：

- Linux / macOS / WSL：`bash build-apk-linux.sh --setup`
- Windows PowerShell：`powershell -ExecutionPolicy Bypass -File build-apk.ps1`

产物路径：`app/build/outputs/apk/debug/app-debug.apk`

也可以直接用 Android Studio 打开本仓库，选择 **Build → Build APK(s)**。

依赖：JDK 17、Android SDK 35、build-tools 35.0.0、Gradle 8.10.2、AGP 8.6.1。
