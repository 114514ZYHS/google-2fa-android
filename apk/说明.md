## 1.3 修复内容

### 修复启动闪退

v1.2 在部分设备上点开即闪退，原因是主题里引入了高版本专有属性：

```xml
<item name="android:windowLightNavigationBar" tools:targetApi="27">true</item>
```

`tools:targetApi` 只是给静态检查看的提示，**并不会阻止该属性被写入 APK 资源表**。
在 API 27 以下的设备上解析这个未知属性会抛异常，导致启动崩溃。

修复方式：把主题按 API 分层，`windowLightNavigationBar` 只放在 `values-v27/`，
基础 `values/` 主题不含该属性。同时把 `minSdk` 提升到 24。

### 补充应用图标

v1.2 及之前**完全没有图标资源**（APK 内 mipmap 条目为 0），
所以桌面上显示的是系统默认安卓机器人。

v1.3 补齐了完整图标：

- 5 种密度 PNG：mdpi 48 / hdpi 72 / xhdpi 96 / xxhdpi 144 / xxxhdpi 192
- 自适应图标（`mipmap-anydpi-v26`），含圆形版本
- 图形为蓝色圆角底 + 白色盾牌 + 锁孔，与验证器调性一致

### 其他健壮性修复

- 进度条统一走 `safeProgress()`，`max` 为 0 或进度越界时不再抛异常
- ToggleGroup 内按钮改用 `Widget.Material3.Button.OutlinedButton` 系样式
- 卡片描边改用 `card_stroke` 选择器，避免选中态取色失败
- `onCreate` 全程 try-catch，万一异常也会把堆栈显示出来而不是直接退出

## 界面结构

界面分上下两块，比例约 **3 : 1**：

**上部（约 3/4）· 账户管理**

- 顶部标题栏：应用名 + 全局倒计时 + 「添加」按钮
- 搜索框：按名称、发行方或密钥过滤
- 工具条：导入 / 导出 / 排序
- 账户卡片列表：每张卡片显示名称、算法参数、大号验证码、剩余时间进度条、复制按钮
- 卡片右上角「⋮」可编辑、置顶、复制密钥、删除
- 点击卡片切换为「当前账户」，同步到下方快速区

**下部（约 1/4）· 快速验证码**

- 显示当前选中账户的名称与大号验证码
- 一键复制按钮
- 剩余时间进度条，剩余 5 秒内转为橙色提示

## 功能

- TOTP 双因素验证码生成
- **位数不受限制**：1～18 位均可，7 位、9 位这类非标准位数同样正确输出
- 支持 SHA1 / SHA256 / SHA512 三种算法
- 支持自定义周期（5～300 秒）
- 支持 `otpauth://` 链接导入，自动识别算法、位数、周期
- 新增账户名称留空时，自动命名为「验证器一」「验证器二」……
- 支持剪贴板导入、文件导入、文件导出
- 账户搜索、置顶、重命名、编辑、复制密钥
- 验证码到期颜色提示

## 关于位数

旧版把位数写死成「6 位或 8 位」两种模式，传入 7 位会按 6 位计算，属于错误行为。
1.2 起改为通用公式 `10^digits`，1～18 位任意长度都按输入值真实计算。
上限取 18 是因为 `long` 能安全表示 `10^18`。

## 关于权限

本应用**不申请任何 Android 权限**。导入导出使用系统文件选择器（SAF），
因此不需要存储权限。账户数据仅保存在本机应用私有目录。

## 测试

```bash
bash tools/algorithm-tests/run.sh
```

包含 4 套算法测试（共 135 项）与 1 套启动路径审计：

- `TotpTest`：RFC 6238 官方向量、多算法、多位数
- `UriTest`：otpauth 解析、中文编码、往返一致性
- `ImportTest`：混合格式导入、去重、边界情况
- `AnyDigitTest`：1～18 位任意位数的正确性验证
- `StartupAudit`：解析 APK 资源表，核对所有 id / 颜色 / 图形 / 样式 / 文案引用
  是否存在、图标是否齐全、主题是否含高版本属性 —— 专门用来防启动闪退
